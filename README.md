# Airbnb Clone

A full-stack Airbnb clone application built with Next.js 13, featuring server-side rendering, secure authentication, and efficient data management. This project showcases modern web development practices and provides a seamless user experience.

## Live Demo

You can view the live application deployed on Vercel here:

[https://airbnb-clone-kp.vercel.app/](https://airbnb-clone-kp.vercel.app/)

## Features

- **Server-Side Rendering (SSR)**: Utilized Next.js 13 to improve initial page load times and SEO.
- **Client-Side Routing**: Enabled smooth navigation and a responsive user experience.
- **Secure Authentication**: Implemented with NextAuth for robust user authentication and session management.
- **Data Management**: Integrated Prisma ORM with MongoDB for efficient and reliable data handling.
- **Media Management**: Leveraged Cloudinary for optimal image storage and retrieval.
- **Backend APIs**: Developed with Next.js API routes to ensure scalable and maintainable code.
- **Enhanced Performance and UX**: Employed TypeScript and Tailwind CSS for better type safety and styling.

## Technologies Used

- **Next.js 13**: Framework for React with built-in server-side rendering and static site generation.
- **NextAuth**: Authentication library for secure and customizable user login.
- **Prisma ORM**: Object-Relational Mapping tool for database management.
- **MongoDB**: NoSQL database for flexible and scalable data storage.
- **Cloudinary**: Cloud service for managing and optimizing media assets.
- **TypeScript**: Superset of JavaScript that adds static typing for improved development.
- **Tailwind CSS**: Utility-first CSS framework for rapid UI development.
